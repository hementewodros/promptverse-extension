# 🚀 PromptVerse

**PromptVerse** is a browser extension that helps users generate AI prompts in **Amharic** — no English required.

---

## 🌍 Why PromptVerse?

Many AI tools require English prompts.

PromptVerse allows Amharic speakers to:
- Search by topic (tag)
- Discover ready-made prompts
- Copy and use instantly

---

## ✨ Features

- 🔎 Tag autocomplete (in Amharic)
- 🧠 Prompt filtering
- 📋 One-click copy
- 💾 Remembers last tag
- ⚡ Fast (fully offline)
- 🎯 Clean, modern UI
